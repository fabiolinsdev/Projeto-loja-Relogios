# Projeto Loja de Relógios

Uma aplicação Full Stack de uma loja virtual de relógios, desenvolvida para praticar e aprender desenvolvimento de um e-commerce moderno. O projeto foi criado para testar a integração entre frontend e backend, com uma interface simples, responsiva e organizada.

## 🌐 Demonstração

O projeto já está disponível na Vercel:

- https://vercel.app

## 🛠️ Tecnologias utilizadas

- Node.js
- React.js
- Fastify
- React Router DOM
- Axios
- Dotenv
- Nodemon
- Vercel

## 📦 Estrutura do projeto

- frontend: interface da loja
- backend: servidor e regras da aplicação

## 🚀 Como rodar localmente

### 1. Clonar o repositório

```bash
git clone https://github.com/fabiolinsdev/Projeto-loja-Relogios.git
cd Projeto-loja-Relogios
```

### 2. Backend

```bash
cd backend
npm install
npm run dev
```

### 3. Frontend

```bash
cd frontend
npm install
npm start
```

Se o frontend for com Vite:

```bash
npm run dev
```

## 🧩 Sobre a loja

Este projeto é uma loja de relógios feita para estudo, com foco em aprender como criar uma aplicação web completa. A ideia é ter uma interface simples, funcional e responsiva, com páginas para visualização dos produtos e uma estrutura que simula um e-commerce básico.

O frontend cuida da parte visual e da navegação, enquanto o backend organiza a lógica da aplicação. Mesmo sendo um projeto de estudo, a estrutura foi pensada para ficar organizada e fácil de entender.
