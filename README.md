# Projeto Loja de Relógios

Este projeto é uma aplicação Full Stack de uma Loja Virtual de Relógios. A ideia principal foi construir uma experiência de compra moderna, limpa e responsiva, separando a parte visual (frontend) da lógica e regras do sistema (backend).

O projeto já está disponível na Vercel:

- https://vercel.app

---

## 🛠️ Tecnologias utilizadas

Para construir a loja, foram usadas ferramentas modernas e muito comuns no mercado:

- Node.js
- React.js
- Fastify
- React Router DOM
- Axios
- Dotenv
- Nodemon
- Vercel

---

## 📦 Estrutura do projeto

O projeto foi dividido em duas partes:

- frontend: interface da loja, páginas e visual
- backend: servidor, rotas e regras da aplicação

---

## 🚀 Como rodar o projeto na sua máquina

### Pré-requisitos

Você precisa ter instalado:

- Node.js
- npm
- Git

### 1. Clonar o projeto

```bash
git clone https://github.com/fabiolinsdev/Projeto-loja-Relogios.git
cd Projeto-loja-Relogios
```

### 2. Rodando o backend

```bash
cd backend
npm install
npm run dev
```

Também pode ser usado:

```bash
node server.js
# ou
node src/server.js
```

### 3. Rodando o frontend

Abra outro terminal e execute:

```bash
cd frontend
npm install
npm start
```

Se o projeto estiver usando Vite, pode ser:

```bash
npm run dev
```

Prontinho! O projeto ficará disponível em:

- http://localhost:3000
- ou http://localhost:5173

## 🧩 Sobre a loja

Este projeto é uma loja de relógios feita como estudo para praticar desenvolvimento Full Stack. A ideia foi criar uma interface simples, responsiva e funcional, simulando uma loja virtual de produtos.

O frontend cuida da parte visual e da navegação, enquanto o backend organiza a lógica e a comunicação com a aplicação. Mesmo sendo um projeto de estudo, a estrutura foi pensada para ficar organizada e fácil de entender.
