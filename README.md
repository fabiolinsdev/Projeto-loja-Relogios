# Projeto Loja de Relógios

Uma aplicação Full Stack de uma loja virtual de relógios, desenvolvida para oferecer uma experiência de compra moderna, responsiva e elegante. O objetivo do projeto foi criar uma plataforma que reunisse uma interface visual bem estruturada com uma API robusta, separando claramente o frontend da lógica de negócio do backend.

A loja foi pensada para simular uma experiência de e-commerce profissional, com foco em usabilidade, organização de conteúdo e navegação fluida para o usuário.

## 📦 Estrutura do projeto

O repositório está dividido em duas partes principais:

- frontend: aplicação visual da loja, componentes, páginas e estilo
- backend: servidor, rotas, regras de negócio e comunicação com a API

## 🚀 Requisitos

Antes de executar o projeto, você precisa ter instalado:

- Node.js
- npm
- Git

## ▶️ Como rodar localmente

### 1. Clonar o repositório

```bash
git clone https://github.com/fabiolinsdev/Projeto-loja-Relogios.git
cd Projeto-loja-Relogios
```

### 2. Iniciar o backend

```bash
cd backend
npm install
npm run dev
```

Também é possível iniciar o servidor com:

```bash
node server.js
# ou
node src/server.js
```

### 3. Iniciar o frontend

Abra outro terminal e execute:

```bash
cd frontend
npm install
npm start
```

Se o frontend estiver usando Vite, a execução pode ser:

```bash
npm run dev
```

O projeto ficará disponível em um endereço local, normalmente em:

- http://localhost:3000
- ou http://localhost:5173

## 🧩 Sobre a loja

A Loja de Relógios é uma aplicação focada em proporcionar uma experiência de compra moderna, limpa e acessível para quem busca relógios com design diferenciado e visual sofisticado. A interface foi projetada para ser responsiva e funcional em diferentes dispositivos, permitindo que o cliente navegue com facilidade e tenha uma boa experiência de uso.

A proposta da aplicação é unir estética e funcionalidade, garantindo ao usuário uma jornada simples e agradável durante a visita à loja. O frontend cuida da apresentação e da navegação, enquanto o backend organiza a lógica, a integração e a comunicação com o cliente.

Essa separação entre front e back torna o projeto mais organizado, escalável e fácil de evoluir com novas funcionalidades.
